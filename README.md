# Void Builder Filter Tags datapack
The goal of this datapack is to create a storage network for the Void Builder Minecraft server utilizing the mods, [Tom's Simple Storage](https://www.curseforge.com/minecraft/mc-mods/toms-storage) and [Sophisticated Storage](https://www.curseforge.com/minecraft/mc-mods/sophisticated-storage). Once completed any player should be able to transfer items in and out of the storage network without needing to interact with the chests themselves, eliminating the confusion of what goes in what chest.

Check out the wiki tab for more information.

This is still a WIP there will be frequent changes happening.
