# Void Builder Filter Tags datapack
Extra tags created for storage organization and filtering use on The Void Builder Minecraft server.

---

**Total Boxes So Far: 19 of 152**  
152 is the count of _double_ chests assuming the number given in the build tut is counting the amount of single chests. Also considering we've edited the roof a bit and don't need to interact with the actual chests there might be more once the build is complete.

Basic Filters can only match by item and only up to 9 items. Advanced filters can also match by item and up to 16 items but they can also match by tag with an "infinite" amount of tags. This is why we are creating custom tags to organize the chests in the storage building.

If only the storage terminal, wireless terminal or advanced wireless terminal is used to move items in/out of the chests they should only be able to go to the "correct" chest.

For items that have been stylized with the modded crafting stations from the Chipped mod, please turn them back to their original state before storing.

The following outline is of chests and their filters. Feel free to give the boxes creative names. Swearing is fine, but please don't go overboard.
